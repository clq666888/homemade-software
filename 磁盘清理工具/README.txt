磁盘清理工具
表格已启用双缓冲以减少滚动闪烁；滚动期间暂缓自动排序，停下后继续更新顺序。
源码已按职责放入 src 文件夹；Program.cs 仅为入口。双击 build.cmd 重新构建，维护说明见 DEVELOPMENT.md，项目文件为 DiskCleanupTool.csproj。
Delete 删除选中项（询问确认后移入回收站），Ctrl+A 选中当前可见项，Ctrl+F 定位名称搜索，F5 刷新当前页，Alt+Enter 打开系统属性。编辑备注文字时 Delete 仍用于删文字。
搜索仅筛选当前目录这一层的文件和文件夹名称，不区分大小写；匹配文字显示黄色底色。清空搜索恢复全部项目，进入另一个目录时自动清空搜索。右键菜单最后一项“属性”打开 Windows 原生属性窗口。
应用图标已嵌入 EXE，窗口和任务栏也使用该图标；图标源文件为 assets/app.ico。
双击 磁盘清理工具.exe 启动，Windows 会要求确认管理员权限；首次打开 C:\，以后恢复上次查看的目录。
名称、修改时间、文件大小三列右端的三角形可点：默认→倒序→正序→默认。
按大小排序时，每算完一个文件夹即更新顺序，计算中的项目暂排在后面。连续结果会在约 0.2 秒内合并排序；拖选、右键菜单或编辑期间暂缓移动，操作结束后继续排序。
文件名前的图标使用 Windows 当前的文件类型关联图标。双击文件夹或图标进入。
在文件名或图标列拖动可连续多选；按住 Ctrl 单击可逐项选中或取消。
点任一选中行的清理状态，会将同一状态应用到所有选中行；蓝色表示当前选中。
表格仅显示文件或文件夹名称，顶部目录栏显示当前完整目录。选中名称后按 Ctrl+C 仍复制完整路径；按 F2 可以选取名称中的一部分文字并复制。
在任一行右键可复制路径、用资源管理器定位路径，或将选中项移入回收站。
右键第一项“刷新选中项”只重新读取选中项目的时间、大小和访问情况；已不存在的选中项目会从当前列表移除。
移入回收站前显示数量并询问确认；失败不会改为永久删除。清空回收站后才释放磁盘空间。
删除后当前列表会更新；只有已删除路径及其上级的大小缓存失效，当前页其他文件夹不会重新计算。
删除后会尽量保持原来的纵向和横向滚动位置；若顶部项目已删除，会停在相邻位置。
可在确认后移入 Program Files、Program Files (x86) 和 ProgramData 内的子项目；这些顶层目录本身仍受保护。工具自身目录也受保护。
初始窗口按屏幕可用空间调整；可缩放分屏。列宽可独立拖动，必要时底部横向滚动。
文件夹大小在后台递归计算；“目录链接”表示该路径指向其他位置，可打开查看，但目标大小不会在这里重复计算。文件夹包含目录链接时显示“+ 链接”。“≥”表示至少已读到这么多，但还有无法读取的内容。“大小未知”表示统计不完整且已读取量为 0；真正空文件夹显示“0 B”。返回上级使用本次运行中的缓存，刷新才重新统计。
“刷新”只重新读取当前目录并重算当前页直接列出的文件夹大小；其他页面的大小缓存保留。
清理状态：未清理（红）、无法访问（黄）、已清理（绿）、不需要清理（深绿）。目录无法读取或文件大小无法取得时自动标黄；鼠标悬停在“无法访问”上可查看实际错误。目录链接能正常打开时不会标黄。旧的“权限不够”状态会转换为“无法访问”。
拖动列宽或调整窗口宽度时，名称和备注列自动填补剩余空间；窗口过窄时可横向滚动。
“重置状态”重置全部路径的状态，保留备注。
备注在右侧编辑，离开单元格或关闭窗口时自动保存。
状态、备注和上次目录分别保存在本文件夹的 status.json、notes.json、lastpath.txt。
“保存配置”会打开“另存为”，由你选择非 C 盘的位置和文件名，默认打开 E 盘工具目录。“导入配置”可选择此前保存的 JSON，校验后替换当前状态和备注。已删除或改名的旧路径不会出现在列表中，也不会影响其他路径；新路径需要重新标记。旧版保存的“当前配置.json”仍可导入。
“复制 ls”复制当前目录的 PowerShell 命令；“复制给 AI”复制完整清单。
