# 文件万能处理器 0.4.3

双击项目根目录的 **文件万能处理器.exe**。请整体保留 `dist/文件万能处理器`，其中有离线 PDF 引擎、运行库与许可证。无需安装 Python、Node 或开发环境；转换不上传文件。根目录与发行目录 GUI 为相同版本，dist 只放当前版。

## 操作

左栏选择“PDF 处理”，顶部依次为转换、页面编辑、合并、拆分、加密、移除加密、压缩。拖入文件，或点击添加。卡片右侧红色垃圾桶仅移除列表项，不删除磁盘原文件；上移/下移改变处理顺序。点击卡片查看右侧预览。

顶部是文字标签导航，蓝色底线表示当前功能；下面的轻量工具栏只负责文件/页面操作。导航项与操作项之间加竖分隔线；文件列表、处理选项、执行区用横线分开，预览区有独立竖线。无文件时上移、下移不可用；旋转图片只在“转换为 PDF”且有图片时显示。压缩下拉框按最长文字与当前 DPI 测量宽度，说明文字单独换行。

窗口缩小时各区随可用空间调整，选项过多则纵向滚动，开始/下载区始终保留；紧凑文件区显示简短的添加提示。

点击开始，运行中同一个按钮可取消。结果准备好后，**进度条下方**显示下载按钮。单份结果选择名称与位置，多份结果选择保存文件夹；同名自动编号，不覆盖已有文件。取消保存窗口可重试，重新处理/关闭前提示未下载结果。完成的文件可下载，未完成临时文件不会当作结果。

选择保存位置后，立即显示“正在准备下载”，随后显示百分比、已保存/总大小、当前文件、批量份数和平均速度。最后落盘时显示“正在完成保存”并保持动画，全部保存成功才到 100%。上方按钮变为“取消下载”；取消会清理当前未完成文件，已保存的完整文件保留，处理结果仍可重试下载。

各功能分别保留自己的上一批结果。切换到未处理的功能时，下载按钮隐藏、进度归零；切回有结果的功能可继续下载。文件列表或参数改变时，明确标为该功能“上次结果”，不冒充按新参数生成的结果。关闭会检查所有功能尚未下载的结果。

## 功能范围

| 顶部工具 | 支持内容 |
| --- | --- |
| 转换 | PDF、DOC/DOCX、XLS/XLSX、PPT/PPTX、本地 HTML/HTM、JPG/JPEG、PNG、BMP、TIF/TIFF → PDF；PDF → PNG/JPG（逐页）、TXT、DOCX、XLSX、PPTX、HTML。其他输入可先转成 PDF，再导出所选格式 |
| 合并 | 按列表顺序合并；支持混合 PDF、Word、Excel、PPT、HTML 和图片，非 PDF 先转换 |
| 加密 | AES-256 打开密码；原文件已加密时需正确原密码 |
| 移除加密 | 用正确密码生成无密码副本，不提供密码破解 |
| 压缩 | 无损、均衡、小体积；后两种降低图片质量。无缩小收益时保留原大小，不承诺固定比例 |
| 页面编辑 | 所有页面以可滚动缩略图展示；框选、Ctrl/Shift 多选，单页红叉/多选删除，拖到页前后排序，旋转与最多 100 步撤销；至少保留一页 |
| 拆分 | 每页、指定页数拆分生成 ZIP；按比例切割生成裁剪后的 PDF |

### 拆分设置

- **每页**：每一页生成单页 PDF，无需额外参数。
- **指定页数拆分**：选择拆成几份（1–100），每份有两个初始为空的数字框，以 `~` 连接；左框填起始页，右框填结束页，不需要输入任何范围符号。例如两框分别填 `1`、`3`，即包含第 1 至第 3 页；只要单页时两框填相同页码。起始页不能大于结束页，页码必须为正整数且不超出原文件。未选页码不导出，不同份可以重用页面；份数较多时输入区可滚动。
- **按比例切割**：勾选“上下切割”或“左右切割”，右侧选择保留上方/下方或左侧/右侧，输入“保留比例”，默认 50%，允许 0.1%–99.9%。例如保留下方 30%，则裁去上方 70%；按页面显示方向裁剪所有页面，保留原页数和顺序，每个输入文件生成一份裁剪后的 PDF，不分成两半、不逐页拆分、不打包 ZIP。

只有选中对应方式，才展开份数/页码或方向/比例。批量 PDF 分别应用同一设置；有任一页码越界或密码错误，会先报错而不提供半成品。“每页”和“指定页数拆分”统一下载一个 `拆分结果.zip`，内部按来源分文件夹；比例切割直接下载裁剪后的 PDF。原件保留，原件加密时输出 PDF 保留原密码，ZIP 本身不加密。比例裁剪通过调整页面边界保留文字和图形质量，范围外内容仍可能存在于 PDF 数据中，不能用作内容脱敏。

PDF → DOCX 重建可编辑正文，扫描页作为图片保留，不含 OCR，也不承诺原稿复杂表格与排版。PDF 的数字签名在重写后可能失效。交互表单已对字段保留及合并重名处理做检查，但复杂 XFA、签名表单、附件和非常规 PDF 不保证完整兼容。

### Excel、PPT 与网页

- **Excel 输入**：XLS/XLSX 由本机 Microsoft Excel 按工作簿原有打印设置导出 PDF；打印区域、分页会影响结果。宏关闭、只读打开，不更新打开链接；需要已安装并激活的桌面 Excel。
- **PPT 输入**：PPT/PPTX 由本机 Microsoft PowerPoint 导出 PDF，需要已安装并激活的桌面 PowerPoint；动画、视频不会成为动态 PDF。
- **本地网页输入**：接收 HTML/HTM 文件，需保留配套图片、样式和字体的本地资源目录。使用隔离的 Edge（无 Edge 时使用 Chrome）打印，不使用用户浏览器配置；清理脚本/事件处理器/嵌入框架并加内容安全策略，远程资源不加载。支持 UTF-8、带编码声明的常见网页及 UTF-16；不接收网址，不联网下载网页，依赖 JavaScript 的内容不会执行。图片模式 HTML 导出也可重新导入。
- **XLSX 输出**：提取可识别的表格为可编辑单元格；无表格时正文逐行保存，扫描页作为图片嵌入。表格检测可能漏识别或分错列；不恢复原 Excel 公式、图表、合并单元格和样式，不含 OCR。
- **PPTX 输出**：每页一张幻灯片，以图片保留页面外观，混合页面尺寸居中适配；文字、表格、图形不拆成可编辑对象。
- **HTML 输出**：在“网页方式”选择“保留页面外观（图片）”或“可编辑正文（文字）”。前者每页内嵌图片，后者生成可编辑正文、扫描页仍保留图片。均为可离线打开的单个 HTML 文件，不依赖旁边资源文件；不恢复原网站结构、交互、脚本或复杂响应式布局。

上述反向 Office/HTML 导出不需要安装 Office。输出为现代 XLSX/PPTX，不输出旧版 XLS/PPT。Office 等其他输入到非 PDF 格式会经过 PDF，中间会失去原公式、动画等信息；不是 Office 文件间的无损互转。

图片转 PDF 为 A4 自动方向、约 10mm 留白，透明背景变白，JPEG 质量 90、最高约 300dpi，存在有损编码；多页 TIFF 全部转出。图片预览只显示 TIFF 首页，超过 8000 万像素请先缩小。

## 预览与页面保存

PDF 提供实际页面图像及翻页。多选编辑页时不显示单页预览。缩略图按可见区域加载，位图和大图缓存有上限。DOCX 直接读取正文，标准 Word 97–2003 DOC 直接读取二进制正文并缓存，不再因点击文件反复启动 Word；正文预览约 16000 字，不显示完整排版。非标准、加密 DOC 可能不能快速预览。

比例切割时，蓝色虚线标出裁剪边界，半透明灰色表示要裁去的范围；预览下方选择“保留：上方/下方/左侧/右侧”。选择与“保留比例”都会影响实际输出，调整时立即重画遮罩，不重新渲染 PDF。

PDF 预览复用本窗口的渲染进程与已打开文档，缓存最多 20 页并空闲预取相邻页，避免每次翻页重新启动两个进程。首次打开或大型复杂页面仍可能需要等待。文档在本实例私有快照中读取，不锁定原件；正常关闭时清理快照、缓存与预览进程。

需要 Word 完整排版时点击“排版预览”，首次启动 Word 可能较慢。Word → PDF、Word 混合合并与排版预览需要本机安装、激活并可使用 Microsoft Word 桌面版；只有 WPS 或网页版 Word 不够。其他 PDF 功能与 PDF → DOCX 不依赖 Word。

XLSX/PPTX/HTML 提供快速内容预览，XLS/PPT 提示点击“排版预览”；完整排版预览使用对应 Office 或浏览器转换组件。快速内容不执行公式、宏或网页脚本，不显示完整图表和样式。

页面编辑默认生成新文件。勾选“直接修改原文件”后仍须确认准确路径，软件检查原文件大小和修改时间未变化，然后原子替换，并把原件保留为同目录 `.原件-时间-随机值.bak`。备份不会自动清理；恢复时确认文件未占用，再把备份复制回原路径。原文件变化、只读或被占用时停止覆盖，可改用新文件方式。

## 系统与数据

- 面向 Windows 10/11 x64、.NET Framework 4.8，当前只在本机 Windows 11 验证；未在干净机器或全部缩放组合验证。程序未签名。
- 程序无上传、遥测、开机启动或托盘守护。Word 自身的云字体、插件、远程链接和首次授权行为由 Office 配置决定，优先使用本地字体和资源。
- Word 只读打开，关闭宏与打开时的链接更新；导出约 150 秒超时。加密/受保护 Word 可能失败。
- 仅记住上次下载目录：`%LOCALAPPDATA%/LocalFileConverter/settings.xml`。密码不存配置，不传命令行，不写正常日志；密码随本次私有 JSON 作业传给本地引擎，正常结束即删除作业目录。
- 临时目录使用系统 temp 中本实例随机的 `LocalConverterV3-*`、`LocalConverterResults-*`、`LocalConverter-*`、`LocalConverterPreview-*`。正常收尾清理本实例目录，不扫描其他实例。强杀、断电可能留下临时文件，确认软件关闭后再清理。
