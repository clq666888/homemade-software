# 文件万能处理器 1.0.0

双击项目根目录的 **文件万能处理器.exe**。请整体保留 `dist/文件万能处理器`，其中有离线 PDF 引擎、运行库与许可证。无需安装 Python、Node 或开发环境；转换不上传文件。根目录与发行目录 GUI 为相同版本，dist 只放当前版。

从GitHub复制软件时，必须同时取得根EXE和完整当前 `dist/文件万能处理器`；根EXE不是包含全部引擎的单文件程序。本项目不会自动替用户提交/推送，允许Git收录不代表已经上传。自带组件分别在 `dist/文件万能处理器/engine`（PDF/图片）、`audio`（音频转换/降噪）、`ocr`（图片识字）；额外下载的语音引擎和模型单独存于项目根目录 **`外置引擎`**，该目录除说明外不进Git，更新发行包不会删除它。

## 操作

左栏可以选择 **PDF 处理**、**音频处理**、**图片处理**。各工作区与各工具独立管理结果；切换到未处理功能时不会保留别的功能的下载按钮。

### 图片处理

添加或拖入图片，底部缩略图切换文件、红色垃圾桶移除列表项。默认居中预览，滚轮缩放；图片放大到超出画布后，按住鼠标右键拖动查看其他区域，左键仍用于编辑/选文字，中键和空格不移动图片。“适应画布”恢复居中全图，“100%”查看实际像素。一次编辑完成后保留当前缩放和平移位置。“专注画布”收起设置与缩略图；右侧设置可滚动，左栏三项统一尺寸和间距。

| 工具 | 操作与范围 |
| --- | --- |
| 格式转换 | JPG/JPEG/JFIF、PNG/APNG、WebP、AVIF、GIF、BMP、TIF/TIFF、ICO、JPEG 2000（JP2/J2K）输入；九种格式输出。真实解码/编码，不是改后缀。HEIC/HEIF、SVG、相机 RAW、PSD 分层编辑暂不支持 |
| 黑白化 | 灰度保留照片明暗层次，或纯黑白二值化并调整阈值；预览与导出共用处理 |
| 水印 | 文字或自选 Logo 图片；居中、斜向大字、斜向/水平重复、顶/底署名、九宫格定位。字体、颜色、透明度、角度、文字字号、Logo 大小与平铺间距可调，实时预览；颜色标签右侧为放大的可点击色块，旁边浅灰“←（点击选择颜色）”指向色块，透明 PNG 适合作 Logo |
| 压缩 | 默认保留原格式、原尺寸。照片格式提供清晰优先、均衡压缩、体积优先三档；可选择改用 JPG/PNG/WebP/AVIF。尺寸可保持或宽高缩小到75%/50%/25%，直接显示前后宽高；手动画质滑块按需展开。PNG隐藏无效画质设置，只优化存储，仍可能不变或变大；完成后查看前后体积和实际画质 |
| 图片编辑 | 裁剪、圆形马赛克、可重新选择编辑的文字、原创几何图标、叠图、圆形画笔、矩形、椭圆、箭头、尺寸、亮度/对比度、圆形橡皮擦；另有旋转/翻转。拖动时预览实际图形，不用通用选框代替 |
| 滤镜 | 独立顶部入口，16个缩略图选项：原图、经典黑白、黑白硬调、复古棕色、温暖、清冷、鲜艳、柔和、褪色、胶片色调、日落暖橙、青蓝色调、高对比、明亮、低调、反色。强度0–100%，预览与导出共用处理，可批量输出 |
| 文字识别 | 随包中英文离线识别，按文字行显示选择框。点击一行或框选多行，Ctrl追加、Ctrl+A全选、Ctrl+C/按钮复制；不自动生成新图片。可选自动增强、原图、浅色文档、深色背景、票证/浅色底纹 |

画笔、马赛克、橡皮擦的大小用“小—大”滑块调节，线条粗细也使用滑块。调节时画布显示圆圈，鼠标移回图片后圆圈跟随指向；圆圈内就是实际涂抹/擦除范围，不需要估计像素。缩放后滑块仍控制眼前可见大小，实际图片坐标自动换算。点击点涂、拖动连续涂抹；马赛克“颗粒大小”只改变块的粗细，不改变笔刷覆盖范围。橡皮只清新增标注并恢复原色/透明度，不擦原照片；纹理/叠图缓存减少重复计算。

图标、箭头、矩形、椭圆、叠图在按下并拖动时显示实际形状、方向、颜色与透明度，松开后应用；只有裁剪和OCR框选使用选框。添加文字后，再用“添加文字”点击画布上已有文字，右侧会载入内容、字体与样式，输入和样式修改实时显示，无需更新按钮。连续输入合为一次撤销；选中画布文字后按 Delete 或点击“删除选中文字”删除，在输入框中 Delete 仍正常删字。文字更新不将新字直接叠在旧字上；旋转/裁剪后仍可选中。

编辑最多保留100步，可撤销/重做，每张图保留独立工作区。尺寸、调色点击“应用”生效；保持比例时以宽度为准计算高度。图形位置不满意可撤销再放置，不提供完整自由图层工程格式。图片编辑仅导出当前图，其余图片工具支持批量。默认只读原件，结果生成后点击下载选择位置，同名自动编号。

动画/多页图片预览第一帧：转换可保留GIF、WebP、AVIF、APNG、TIFF的多帧/页；转静态格式须明确勾选“仅取第一帧 / 第一页”。黑白、水印、滤镜和编辑为静态图工具，多帧输入须明确取第一帧；识别多帧文件建议先转静态图。单图不超过4000万像素；多帧最多500帧、合计1.2亿像素。ICO透明方形补边、16–256像素多尺寸；GIF最多256色，半透明量化。透明图转JPG/BMP填白底。

输入校正EXIF旋转并尽可能将ICC转sRGB；输出不保留原EXIF/GPS，不保证HDR、16-bit或全部元数据往返。OCR完成后，右侧先显示全部识别文字；点击文字框显示该区域，框选/Ctrl追加多个框会一起显示。默认连成一段，不在每个识别框之间强制换行，中文片段直接衔接，英文保留单词空格；勾选“保留原图换行”可恢复逐行显示，复制内容遵循相同设置。右侧是可选择的只读文本框，可以只选部分字复制；“复制显示文字”优先复制右侧选中的部分，“显示/选择全部”恢复全部内容。重新识别、换文件或换功能时清理旧内容。右键平移不改变文字选择。

OCR默认按整页排版识别，少量分散短字可开启“零散标签模式”。按近基线/字高/间距双向合并片段，避免右侧片段先出现时漏合并，不跨远列或不同行强行拼框；仍不能保证所有碎片都合为一句。增强只用于识别，不改画布和原件。底纹、艺术字、倾斜/模糊或已标注图片仍可能出错，需核对；不把原图中的字变成编辑对象，也未扩展到PDF OCR。模式说明参考[Tesseract官方文档](https://github.com/tesseract-ocr/tessdoc/blob/main/ImproveQuality.md)，不同格式的画质/无损选项参考[Pillow官方文档](https://pillow.readthedocs.io/en/stable/handbook/image-file-formats.html)。

“预览生成文件”用于查看点击下方开始/生成按钮后，真正保存出来的编码结果（如压缩后的画质和尺寸），不是当前编辑草稿。没有生成结果时隐藏，生成后才显示；参数改变会标“上次”。打开后用同一个按钮“返回工作预览”继续编辑，结果视图只读。下载有字节进度与落盘反馈，可取消；关闭检查所有工作区未下载结果/未导出编辑并清理私有目录。全程无需联网、无需另装OCR或字体包。

左栏选择“PDF 处理”，顶部依次为转换、页面编辑、合并、拆分、水印、加密、移除加密、压缩。拖入文件，或点击添加。卡片右侧红色垃圾桶仅移除列表项，不删除磁盘原文件；上移/下移改变处理顺序。点击卡片查看右侧预览。

添加 PDF 时自动检查是否需要打开密码：无需密码则直接加入；需要时弹窗输入并验证。密码错误在同一窗口提示重试，验证成功才加入列表；“取消导入”跳过该文件，继续处理其他文件。不同密码的 PDF 可同批加入，各文件独立使用已验证的密码，切换功能不用重复输入。密码仅在本次运行的内存及本次私有作业中使用，不保存到设置；移除文件或关闭窗口会释放关联。原文件发生变化时重新验证。只有所有者权限限制、空密码即可打开的 PDF 无需额外输入。

各功能不再重复显示“原文件密码”框；“加密”仍保留设置**新的打开密码**的输入框。此导入验证针对 PDF；Office 文件输入仍遵循下方的兼容范围。

顶部是文字标签导航，蓝色底线表示当前功能；下面的轻量工具栏只负责文件/页面操作。导航项与操作项之间加竖分隔线；文件列表、处理选项、执行区用横线分开，预览区有独立竖线。无文件时上移、下移不可用；旋转图片只在“转换为 PDF”且有图片时显示。压缩下拉框按最长文字与当前 DPI 测量宽度，说明文字单独换行。

窗口缩小时各区随可用空间调整，选项过多则纵向滚动，开始/下载区始终保留；紧凑文件区显示简短的添加提示。

点击开始，运行中同一个按钮可取消。结果准备好后，**进度条下方**显示下载按钮。单份结果选择名称与位置，多份结果选择保存文件夹；同名自动编号，不覆盖已有文件。取消保存窗口可重试，重新处理/关闭前提示未下载结果。完成的文件可下载，未完成临时文件不会当作结果。

选择保存位置后，立即显示“正在准备下载”，随后显示百分比、已保存/总大小、当前文件、批量份数和平均速度。最后落盘时显示“正在完成保存”并保持动画，全部保存成功才到 100%。上方按钮变为“取消下载”；取消会清理当前未完成文件，已保存的完整文件保留，处理结果仍可重试下载。

各功能分别保留自己的上一批结果。切换到未处理的功能时，下载按钮隐藏、进度归零；切回有结果的功能可继续下载。文件列表或参数改变时，明确标为该功能“上次结果”，不冒充按新参数生成的结果。关闭会检查所有功能尚未下载的结果。

## 功能范围

### 音频转换与背景降噪

- 拖入本地音频或点击“添加音频”，选择输出格式与质量，点击开始；完成后用下载按钮选择保存位置。默认新文件，同名自动编号，原件保留。
- 首批针对常见格式：MP3、WAV、FLAC、AAC、M4A、OGG、Opus、AIFF、WMA；M4A 分 AAC 和 ALAC 无损两个选项，共 10 个输出选择。不保证私有加密/DRM、损坏或冷门格式可用，不是修改后缀；输入按实际内容识别。
- 提供质量、自动兼容/44.1kHz/48kHz、单/双声道设置。自动声道最多保留双声道；Opus 自动适配 48kHz。WAV 和 AIFF 为 16-bit PCM；有损转无损不能恢复丢失信息。ALAC/FLAC/WAV 没有有损比特率选项。
- 背景降噪使用轻度、均衡、强力三档频谱降噪，可附加抑制 50/60Hz 电流嗡声；适合持续底噪、风扇声和嘶声，不能保证去除背景讲话、音乐、回声或所有突发声。强档可能损伤细节，应先试听。
- 右侧显示音频信息和片段波形；选择起点后点击“生成试听对比”，生成同一起点、最长 15 秒的原声/处理后片段，点击播放按钮比较。处理后试听会先经过所选输出编码，再解码为播放片段，包含编码和降噪影响。未自动播放或上传文件。
- 降噪中间处理采用本地 16-bit PCM；长音频可能产生较大的临时文件，流式处理不把整段装进内存。正常结束、取消和关闭清理本实例处理目录。关闭前提示所有工作区未下载结果。
- 格式转换/降噪的引擎随完整发行目录提供，无需安装 FFmpeg、Python、AI 框架或联网下载模型；这两项不访问云端。音频自带运行文件约 11.85 MiB，未打包通用视频引擎或大型模型。

### 视频处理：格式转换、视频转 GIF

左栏选择“视频处理”。首次点击“联网下载视频引擎”（约92.37MB），或用“导入离线引擎”导入本版锁定的官方ZIP。资源安装到`外置引擎/runtimes/video-ffmpeg-20261125`，不进入Git或dist；安装后完全离线处理。下载与语音资源共用右上角任务图标和最多2项并行队列，下载期间可以切换页面，支持取消、继续及重试。大小和SHA256匹配、解压及安装收据全部完成才启用，不自动下载、不上传视频。完整资源包解压约236.6MB；保留配套DLL、文档与许可证，不靠盲删库缩小体积。

- **格式转换**：输入常见MP4、MKV、MOV、AVI、WebM、WMV、FLV、M4V、MPG/MPEG、TS/M2TS、3GP、OGV，输出MP4、MKV、MOV、WebM、AVI、WMV。按实际流识别，不是改后缀；不承诺DRM、损坏及全部冷门编码。选择输出格式、清晰度、画面大小及保留声音。默认重新编码，仅输出第一路视频和第一路音频；字幕、额外音轨及附件不输出，音频最多双声道，HDR/色彩/无损还原不保证保留。尺寸不放大，视频自动适配偶数像素；文件大小取决于源内容与设置。
- **视频转 GIF**：默认前5秒，不足则取实际时长。可填写起止秒数，或拖动右侧时间条再点击“设为起点/终点”，同时显示时分秒范围与持续时间。终点须在视频内且晚于起点，每段最长120秒；无效范围以红字提示并禁用生成。可选宽度320/480/720/1080、每秒8/12/20/25帧、是否循环；不放大小视频，最长边限制1280。GIF没有声音；长片段、高清和高帧率可能使文件明显变大。
- **预览与批量**：右侧显示实际画面、尺寸与时长，拖动时间条查看该位置的静帧。“预览GIF（前3秒）”用实际导出设置生成会动的短预览；“返回视频画面”恢复源帧。点击“生成GIF”才生成完整所选片段；32MB以内的最终GIF直接在右侧展示。批量使用同一组设置；GIF范围必须适合列表中所有文件，超范围先报错，不静默缩短。普通视频不提供声音播放或边转边播放。
- **下载与原件**：先生成结果再下载选位置；同名自动编号，原件保留。两个功能结果隔离，参数改变标明“上次”；GIF设置不误标视频转换结果。生成/保存有进度、可取消，关闭检查所有未下载结果并等待取帧/处理进程退出。输入需能读出有限时长，单帧不超过4000万像素。

引擎使用[FFmpeg构建方固定版本](https://github.com/FFmpeg-Builds/FFmpeg-Builds/releases/tag/autobuild-2026-11-25-12-41)，GIF使用[官方palettegen/paletteuse滤镜](https://ffmpeg.org/ffmpeg-filters.html#palettegen)的两遍调色板处理，避免堆积整段视频帧。精确版本、大小、散列见`src/VideoCatalog.cs`。仅支持本地文件，拒绝网络输入及网络播放列表。

语音生成需要一个共用引擎，再任选一套音色包即可。Kokoro v1.1（推荐）提供100个中文男女声及3个英语女声；v1.0（可选）在本软件提供28个英语男女声及8个中文男女声，两套并非必须同时安装。

“离线安装官方包”接受当前所选资源的指定官方原件，点击后可复制准确下载地址与SHA256；“导入自定义音色”仅接受按本软件规范封装的兼容Kokoro ZIP，导入前会展示格式和限制。普通录音和其他软件语音包不能通用导入；自制包结构检查通过不代表实际合成一定成功，须先试听。详细规范见[音色包说明](docs/VOICE_PACKS.md)，发行版内的导入说明也包含清单示例。

试听使用更短的固定短句；同一音色、语言、语速和资源版本重复试听会直接重播缓存，不重新生成。当前会话最多保留12段、总计16MiB，关闭清理；更换音色后返回可复用，资源文件变化时不复用。首次或未缓存的声音仍需载入模型，不能保证即时生成。

Kokoro v1.1中文音色显示官方zf/zm编号（官方编号并不连续），没有未经验证的“萝莉音/奶龙”等标签。v1.0另有晓贝、晓妮、云健等具名音色。可给当前音色添加个人备注并收藏，再勾选“只看收藏”；备注不会改变模型或音色Id。设置保存在本机LocalApplicationData/LocalFileConverter/voice-preferences.json，不随Git分发。其他模型家族即使有角色名，也不能通过当前Kokoro导入口直接使用。

### 功能扩展包下载

点击主窗口右上角下载图标，打开统一的“功能扩展包下载”。按用途分组列出全部7项官方下载资源，以及已导入的兼容音色包；不只显示本次下载任务，也不把软件自带的PDF/图片/音频组件混进来。每项右侧有小感叹号，鼠标停留显示对应功能、所需配套资源及共享关系。

界面参考[VS Code扩展列表](https://code.visualstudio.com/docs/configure/extensions/extension-marketplace)与[Fluent列表规范](https://fluent2.microsoft.design/components/web/react/core/list/usage/)，沿用本软件蓝灰配色：功能分组采用更大加粗标题与蓝色标记，资源采用连续紧凑行、细分隔线和细进度条，说明与操作按钮同行，避免大卡片占用空白。窗口缩小时仅纵向滚动，仍可看到完整的首个功能分组。

- **未下载**：空进度条，右侧点击“下载”；**已下载**：绿色完整进度条及“已下载”，可卸载。
- **下载中**：显示百分比及下载信息，提供独立的“暂停”和“取消下载”。最多同时下载/安装2项，其余排队；关闭管理窗口继续后台下载。
- **暂停**：保留下载片段，之后点击“继续下载”续传。重启软件后仍会发现已保留的官方资源片段。
- **取消下载**：先弹窗告知已下载部分会删除、进度会丢失，之后需要重新下载。默认“保留下载”，叉号或Esc也保留；只有明确点击“取消下载”，才等待本资源后台写入结束，删除它的未完成下载，进度归零；不会取消其他资源，也不会删除已经安装完成的资源。若文件权限导致清理失败，会明确提示失败，不能假报已删除。
- **卸载**：确认后移除本项已登记资源及残留下载片段，不删除输入文件、生成结果、其他模型或音色包。共享引擎会提示受影响功能；正在被语音处理、视频处理或取帧任务使用的资源暂不可卸载。卸载后可重新下载；本地导入包没有固定下载源，需保留原ZIP以便重新导入。

退出软件会暂停未完成下载、保留进度，并等待正在清理/卸载的任务结束。已经卸载的资源会自动从相关功能可用状态中移除；处理按钮在所需资源再次完整安装前禁用。

### 语音转文字与语音生成

音频顶部增加“语音转文字”和“语音生成”。两项均为可选资源：**未安装时仍显示完整界面、联网下载提示，处理/试听按钮禁用**。点击下载才访问官方GitHub/Hugging Face，资源任务独立在后台执行，下载/校验/安装期间可以切换工作区。最多同时下载/安装2个资源，其余排队；可继续选择资源添加，共用引擎去重。右上角统一管理全部外置资源、进度、暂停续传、取消删除及卸载；图标角标显示活动任务数。关闭管理窗口继续下载，退出软件则暂停并保留片段。

下载后校验SHA256、解压到临时目录，全部完成才启用；下载失败不会显示为已安装。资源齐全后离线运行，音频与文字不上传。不便联网时可用“导入离线资源”导入本版锁定的官方文件；同一资源正在后台安装时需先等待或取消，避免重复覆盖。语音转写/生成本身仍显示处理状态并允许取消，未安装齐所需资源前不会提前启用。

- **转文字**：提供轻量Tiny Q5_1和均衡Base Q5_1中英文模型，首次需要Whisper CPU引擎；一次处理当前音频，可选自动/中文/English。结果可选TXT或SRT：TXT正文可校对并复制、保存校对内容；SRT保留识别时的原始时间轴。模型尤其轻量版可能漏字/错字，应核对；不承诺嘈杂录音、方言、混语或全部长录音准确。
- **生成语音**：使用sherpa-onnx CPU引擎，提供Kokoro v1.1中英文103音色包，以及含英语男声、中文男女声的v1.0扩展包。可按语言/性别筛选、试听短句，选语速后生成全文，输出WAV/MP3/FLAC。最多5000字，处理可取消。音色风格以试听为准，不把升降音调冒充自然新音色。
- **后续扩展**：“导入音色包”可加入配套模型/音色向量/词典的兼容Kokoro ZIP，不需要改软件代码；导入后如果缺CPU引擎仍需下载。格式和示例见[音色包说明](docs/VOICE_PACKS.md)，其他模型家族需要相应适配器。
- **存放位置**：`外置引擎/runtimes` 存额外引擎，`models` 存识别模型，`voice-packs` 存音色包，`downloads` 存续传片段。下载/导入完成后自动更新状态；复制或移除兼容的已安装资源目录也会自动检测，无需手动刷新，且保留当前文字与选择。手工放入压缩包仍需使用“导入离线资源”或“导入音色包”校验安装；检测不绕过完整性校验。便携迁移时连同此目录复制即可。首次下载体积不等于Git体积，下载内容被忽略；软件默认不预装这些模型。

当前锁定下载量（十进制）：Whisper引擎3.83MB、Tiny模型32.15MB、Base模型59.71MB；语音生成引擎28.56MB、v1.1音色包147.05MB、v1.0音色包132.35MB。解压占用会更大，按所选包下载，共用引擎只下载一次。语音功能目标为Windows x64，Whisper中文命令行兼容要求Windows10 1903及之后版本；TAR资源安装使用系统自带tar，未验证更早系统。精确版本/散列见 `src/SpeechCatalog.cs`，资源许可证保留原包内容与上游来源。

### 文字水印

选择“水印”并添加 PDF，输入需要的文字。“选择字体”使用本机字体，支持粗体、斜体；还可调字号、角度、不透明度、颜色、平铺间距、边距以及空心描边。样式有居中大字、斜向大字、斜向平铺、水平平铺、页眉、页脚、九宫格定位；位置直接点击 3×3 九宫格，蓝格表示当前位置，也可用方向键选择。颜色入口显示实际颜色小方块，点击选择颜色，不显示颜色编码。切换样式给出相应默认字号和角度，仍可继续调整。过长文字会自动缩小以适应页面。

右侧立即重画水印，翻页检查不同页面尺寸。可应用全部、仅奇数、仅偶数或指定范围；范围用两个数字框 `起始页 ~ 结束页`，不需要手写范围符号。未应用的页面明确显示“此页不加水印”。修改水印不重新渲染 PDF；选项较多时左侧纵向滚动。

点击“开始水印”，每个输入输出一份新 PDF，再选择下载位置。原文件保留；加密原件需正确密码，输出继续保留原密码。水印以透明图像层嵌入，预览与导出共用绘制逻辑，接收者无需安装所选字体；原页面正文、图片和表单保留，不整页栅格化。水印文字本身不是可搜索的 PDF 文字层，也不是防篡改保护。

### 拆分设置

- **每页**：每一页生成单页 PDF，无需额外参数。
- **指定页数拆分**：选择拆成几份（1–100），每份有两个初始为空的数字框，以 `~` 连接；左框填起始页，右框填结束页，不需要输入任何范围符号。例如两框分别填 `1`、`3`，即包含第 1 至第 3 页；只要单页时两框填相同页码。起始页不能大于结束页，页码必须为正整数且不超出原文件。未选页码不导出，不同份可以重用页面；份数较多时输入区可滚动。
- **按比例切割**：勾选“上下切割”或“左右切割”，右侧选择保留上方/下方或左侧/右侧，输入“保留比例”，默认 50%，允许 0.1%–99.9%。例如保留下方 30%，则裁去上方 70%；按页面显示方向裁剪所有页面，保留原页数和顺序，每个输入文件生成一份裁剪后的 PDF，不分成两半、不逐页拆分、不打包 ZIP。

只有选中对应方式，才展开份数/页码或方向/比例。批量 PDF 分别应用同一设置；有任一页码越界或密码错误，会先报错而不提供半成品。“每页”和“指定页数拆分”统一下载一个 `拆分结果.zip`，内部按来源分文件夹；比例切割直接下载裁剪后的 PDF。原件保留，原件加密时输出 PDF 保留原密码，ZIP 本身不加密。比例裁剪通过调整页面边界保留文字和图形质量，范围外内容仍可能存在于 PDF 数据中，不能用作内容脱敏。

PDF → DOCX 重建可编辑正文，扫描页作为图片保留，不含 OCR，也不承诺原稿复杂表格与排版。PDF 的数字签名在重写后可能失效。交互表单已对字段保留及合并重名处理做检查，但复杂 XFA、签名表单、附件和非常规 PDF 不保证完整兼容。

### Excel、PPT 与网页

- **Excel 输入**：XLS/XLSX 由本机 Microsoft Excel 按工作簿原有打印设置导出 PDF；打印区域、分页会影响结果。宏关闭、只读打开，不更新打开链接；需要已安装并激活的桌面 Excel。
- **PPT 输入**：PPT/PPTX 由本机 Microsoft PowerPoint 导出 PDF，需要已安装并激活的桌面 PowerPoint；动画、视频不会成为动态 PDF。
- **本地网页输入**：接收 HTML/HTM 文件，需保留配套图片、样式和字体的本地资源目录。使用隔离的 Edge（无 Edge 时使用 Chrome）打印，不使用用户浏览器配置；清理脚本/事件处理器/嵌入框架并加内容安全策略，远程资源不加载。支持 UTF-8、带编码声明的常见网页及 UTF-16；不接收网址，不联网下载网页，依赖 JavaScript 的内容不会执行。图片模式 HTML 导出也可重新导入。
- **XLSX 输出**：提取可识别的表格为可编辑单元格；无表格时正文逐行保存，扫描页作为图片嵌入。表格检测可能漏识别或分错列；不恢复原 Excel 公式、图表、合并单元格和样式，不含 OCR。
- **PPTX 输出**：每页一张幻灯片，以图片保留页面外观，混合页面尺寸居中适配；文字、表格、图形不拆成可编辑对象。
- **HTML 输出**：在“网页方式”选择“保留页面外观（图片）”或“可编辑正文（文字）”。前者每页内嵌图片，后者生成可编辑正文、扫描页仍保留图片。均为可离线打开的单个 HTML 文件，不依赖旁边资源文件；不恢复原网站结构、交互、脚本或复杂响应式布局。

上述反向 Office/HTML 导出不需要安装 Office。输出为现代 XLSX/PPTX，不输出旧版 XLS/PPT。Office 等其他输入到非 PDF 格式会经过 PDF，中间会失去原公式、动画等信息；不是 Office 文件间的无损互转。

图片转 PDF 为 A4 自动方向、约 10mm 留白，透明背景变白，JPEG 质量 90、最高约 300dpi，存在有损编码；多页 TIFF 全部转出。图片预览只显示 TIFF 首页，超过 8000 万像素请先缩小。

## 预览与页面保存

PDF 提供实际页面图像及翻页。多选编辑页时不显示单页预览。缩略图按可见区域加载，位图和大图缓存有上限。DOCX 直接读取正文，标准 Word 97–2003 DOC 直接读取二进制正文并缓存，不再因点击文件反复启动 Word；正文预览约 16000 字，不显示完整排版。非标准、加密 DOC 可能不能快速预览。

比例切割时，蓝色虚线标出裁剪边界，半透明灰色表示要裁去的范围；预览下方选择“保留：上方/下方/左侧/右侧”。选择与“保留比例”都会影响实际输出，调整时立即重画遮罩，不重新渲染 PDF。

PDF 预览复用本窗口的渲染进程与已打开文档，缓存最多 20 页并空闲预取相邻页，避免每次翻页重新启动两个进程。首次打开或大型复杂页面仍可能需要等待。文档在本实例私有快照中读取，不锁定原件；正常关闭时清理快照、缓存与预览进程。

需要 Word 完整排版时点击“排版预览”，首次启动 Word 可能较慢。Word → PDF、Word 混合合并与排版预览需要本机安装、激活并可使用 Microsoft Word 桌面版；只有 WPS 或网页版 Word 不够。其他 PDF 功能与 PDF → DOCX 不依赖 Word。

XLSX/PPTX/HTML 提供快速内容预览，XLS/PPT 提示点击“排版预览”；完整排版预览使用对应 Office 或浏览器转换组件。快速内容不执行公式、宏或网页脚本，不显示完整图表和样式。

页面编辑默认生成新文件。勾选“直接修改原文件”后仍须确认准确路径，软件检查原文件大小和修改时间未变化，然后原子替换，并把原件保留为同目录 `.原件-时间-随机值.bak`。备份不会自动清理；恢复时确认文件未占用，再把备份复制回原路径。原文件变化、只读或被占用时停止覆盖，可改用新文件方式。

## 系统与数据

- 面向 Windows 10/11 x64、.NET Framework 4.8，当前只在本机 Windows 11 验证；未在干净机器或全部缩放组合验证。程序未签名。
- 程序无上传、遥测、开机启动或托盘守护。Word 自身的云字体、插件、远程链接和首次授权行为由 Office 配置决定，优先使用本地字体和资源。

- 临时目录使用系统 temp 中本实例随机的 `LocalConverterV3-*`、`LocalConverterResults-*`、`LocalConverter-*`、`LocalConverterPreview-*`。正常收尾清理本实例目录，不扫描其他实例。强杀、断电可能留下临时文件，确认软件关闭后再清理。
