# 按需下载的外置引擎

此目录仅保存用户选择额外下载或本地导入的引擎、模型和音色包，不存放软件自带组件。

- `runtimes/`：额外下载的处理引擎；`video-ffmpeg-20261125`为视频转换/GIF共用引擎，语音引擎也在各自子目录。
- `models/`：额外下载的语音识别模型。
- `voice-packs/`：已下载或导入的兼容音色包。
- `downloads/`：尚未完成的下载；暂停/退出保留供续传，点击“取消下载”会清除对应片段。

除本说明外，整个目录内容被 Git 忽略，不会增加仓库模型体积。不要把下载的引擎复制到 `dist`；更新程序会保留本目录。便携迁移时可连同本目录一起复制，资源齐全后无需联网。

软件自带组件仍在 `dist/文件万能处理器/engine`、`audio`、`ocr` 下。

视频引擎下载约92.37MB，解压约236.6MB，不进入Git。使用软件提供的下载或官方离线ZIP导入完成校验，不要只拷ffmpeg.exe，配套DLL及许可证须保留。下载共用右上角任务入口；没有视频引擎时展示完整界面，暂不可处理。

右上角“外置引擎管理”按用途列出全部官方下载资源及兼容导入音色包，显示已下载/未下载/进度并提供暂停、取消下载与卸载。悬停感叹号可查看功能关联。卸载只删除选中资源；正在处理文件的资源暂不可卸载。音色包没有固定下载源，卸载后需要重新导入自己的ZIP。
